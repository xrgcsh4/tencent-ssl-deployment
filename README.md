## 腾讯云ssl证书部署的三条路线，对号入座

三条路线没有绝对优劣，对应的是三种不同的证书落点：腾讯云资源、自建服务器，以及不想在任何服务器上装证书的场景。

### 路线一：一键部署到腾讯云资源

证书要挂在 CDN、负载均衡等腾讯云资源上时，这是最省事的方式。在 SSL 证书控制台找到已签发的证书，选择部署目标即可，不用下载证书文件，也不用登录服务器。这条路线的适用对象是腾讯云自家的云服务，覆盖面是 11 种资源。

有一个申请阶段就要注意的细节：如果计划把证书部署到负载均衡、CDN 这类云服务，申请证书时不要填写私钥密码。腾讯云的证书申请页对此有明确提示。很多人是申请完、部署失败时才回头找原因，重新走一遍申请流程很耽误时间。

### 路线二：手动安装到自建服务器

自建 Nginx、Apache、IIS 环境，走的是下载证书加手动安装。控制台会按服务器类型提供对应的证书文件，安装文档也按 Linux 和 Windows 系统分开写。

流程大致是：从控制台下载证书，上传到服务器，按对应服务器类型的官方文档修改配置，然后重载服务。具体命令照安装文档来，不同服务器写法差别不小，这里不展开。

续期有一个容易忽略的成本：证书续期相当于重新申请一张新证书，旧证书不会因此延长有效期。新证书签发后要重新部署一遍，服务器上的配置也得同步更新。免费证书在过期前 30 天可以走快速续期通道，续期本身不收费，但“重新装一遍”这件事省不掉。

### 路线三：一键 HTTPS，不碰服务器

这条路线适合不想在服务器上维护证书的人。原理是把域名接入腾讯云 Web 应用防火墙（WAF），HTTPS 在 WAF 层完成，源站可以继续保持 HTTP。

操作分三步：

1. 在“一键 HTTPS（安全防护版）”页面添加域名。选一张已签发的证书（证书绑定的域名要和你填的域名一致），填源站 IP 或源站域名，按需开启强制 HTTPS（开启后 HTTP 请求会以 302 状态码跳转到 HTTPS），再选回源协议和回源端口。回源端口默认支持 80 或 8080。
2. 配置 CNAME。域名托管在 DNSPod 的可以一键添加记录；其他解析商就手动加，记录类型选 CNAME，线路类型选默认，记录值填控制台给出的 CNAME 域名。
3. 等解析生效。生效时间一般和你设置的 TTL 一致，默认是 600 秒。

限制也要提前知道，不然配到一半才发现走不通：

- 域名必须完成 ICP 备案，这是硬性前提，没备案的域名添加不进去。
- 服务默认开通 WAF 小微版：支持 1 个二级域名、8 个子域名、50 QPS。www 子域名也占一个子域名名额。
- 域名已经接入腾讯云 CDN 或 CLB 的，不能再用一键 HTTPS。

## 免费证书的四个限制，申请前先知道

大多数个人站、博客和测试环境用免费 DV 证书就够，但它的限制比付费证书多，提前了解能少走弯路。

**域名范围有限**。免费证书只支持二级域名及其子域名申请，不支持 IP 和泛域名。子域名多的站点要一张张申请，管理起来琐碎。

**有申请名额上限**。按腾讯云的免费证书名额说明，亚洲诚信体系内同一主域最多只能申请 20 张免费证书，在其他平台申请过的同主域证书也会计入。申请时留意目标域名是否已经在别处占用过名额。

**续期要重新部署**。免费证书到期前 30 天可以快速续期，新证书签发后需要重新安装到服务器或云资源上，旧证书不会自动延续。

**验证方式要选对**。域名托管在 DNSPod 的，可以用自动 DNS 验证；不在的话，手动添加 DNS 记录或用文件验证。验证通过后 CA 在 24 小时内完成签发。

申请入口在 SSL 证书控制台的“我的证书”页面，点“申请免费证书”，填单个域名，选验证方式，提交后等签发。前提是账号已完成实名认证。

## 常见问题

**免费证书能部署到 CDN 和负载均衡吗？**

可以部署，但申请时不要设置私钥密码，否则会影响后续部署到这些云服务。

**证书部署后多久生效？**

部署到服务器，安装完成后即生效；一键 HTTPS 依赖 CNAME 解析，生效时间一般与 TTL 设置一致。

**一键 HTTPS 添加域名失败是什么原因？**

常见原因有两个：域名没有完成 ICP 备案，或者域名已经接入了腾讯云 CDN 或 CLB。

**免费证书到期了怎么办？**

到期前 30 天在控制台点“快速续期”，重新申请一张新证书并部署。免费证书续期不收费。
